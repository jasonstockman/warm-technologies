# Warm Technologies

A simple one-page company/SaaS website template for Warm Technologies LLC.

## Research notes

The template borrows common patterns from simple modern SaaS sites:

- Linear: dark/premium product-led positioning, compact navigation, realistic product UI panels.
- Resend: developer-friendly hero, badge + headline + dual CTA, code/product-preview sections.
- Dub: light minimal SaaS layout, early proof, outcome-focused copy, repeated feature cards.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS v4
- shadcn-style components
- lucide-react icons
